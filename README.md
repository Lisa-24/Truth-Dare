
# Truth & Dare Web App



## Description

A simple Truth & Dare game built using HTML, CSS, and JavaScript.
It features a clean user interface with soft colors and randomly generated truth questions and dare challenges.



## Features

* Random truth and dare generator
* Clean and minimal user interface
* Soft gradient background design
* Responsive centered layout
* Lightweight and beginner-friendly



## Project Structure


truth-dare-game/
│
├── index.html
├── style.css
└── script.js




## How to Run

1. Download or clone the project
2. Open the project folder
3. Open index.html in your browser


## Or using Git.


git clone https://github.com/Lisa-24/Truth-Dare.git
cd truth-dare-game
open index.html




## How to Use

1. Open the application in a browser
2. Click "Truth" to get a random question
3. Click "Dare" to get a random challenge



## Technologies Used

* HTML5
* CSS3
* JavaScript
